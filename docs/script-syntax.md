# スクリプト構文リファレンス（暫定）

- 状態: **暫定**。実装前であり、確定していない
- 根拠: `drafts/sample-short.wn` を書いた結果として抽出したもの
- 方針: [初期要件と保存設計](decisions/2026-08-07-initial-requirements-and-save-design.md) の目標1に従い、
  **台本に出てこない命令は載せない**

この一覧は「あったら便利そうな機能」ではなく「実際に台本が要求した機能」だけを記録している。
台本を書き足した結果として必要になった命令だけを、ここに追加していく。

## 第一原則

**無記号のプレーンテキストが、そのままで最小の台本として成立すること。**

記法なしの原稿がパースエラーになってはならない。演出はすべて後付けの差分である。

## 行頭記号

| 記号 | 意味 |
|---|---|
| `#` | コメント |
| `=` | シーン宣言 |
| `@` | 演出指示 |
| `>` | 話者（次の1ブロックのみ有効） |

これ以外で始まる非空行はすべて本文。

## 本文ブロック

**改行が区切り。1行が1ブロックであり、クリック1回分。空行は無視される。**

```
窓際の机に印刷したての部誌の束が積んである。明日の朝、昇降口で配る分だ。
```

改行を入れなければ何文でも1ブロックで、途中でクリックは要らない。
文字送りが流れ続け、行末で1回だけクリック待ちになる。

行がメッセージ枠に収まらない場合は自動でページ送りする（そこでクリック1回）。
それが不都合なら、書き手が改行して調整する。

空行に意味は無く、書き手が段落を見やすくするためだけのもの。

本文ブロックはセーブ連番の単位であり、既読ハッシュの単位でもある。

## テキストの種類

| 書き方 | ネームプレート | 用途 |
|---|---|---|
| 記号なしの行 | 出さない | 地の文、主人公のモノローグ |
| `「…」` | `@protagonist` の名前 | 主人公の発話 |
| `>名前` の直後の `「…」` | その名前 | 他の人物の発話 |
| `>` （引数なし）の直後 | 出さない | 話者を伏せる |

`「」` は制御文字ではない。約物として本文中で自由に使える。

```
ミカは「うん」とだけ言って、椅子に座り直した。
```

行頭が `「` でないため地の文として扱われる。

### 話者の指定

`>` の引数は**キャラクターIDではなく表示名そのもの**。事前登録は不要。

```
>ミカ
「おつかれ。刷り上がったよ」

>？？？
「読んでくれた?」
```

叙述トリックのために実名を伏せる用途をそのまま書ける。
誤字は検出しない（登場人物リストを持たないため）。最終確認は人間または AI が行う。

`>` は**直後の1ブロックにのみ**効く。状態を持たないため、
行の挿入・移動・切り取りで話者の解釈が変わらない。

## シーン宣言

```
= scene 部室・放課後
```

シーンはセーブ位置の座標であり、復元時のリプレイ開始点。

### シーン境界での状態

**背景・BGM・立ち絵・その他の演出状態は、シーンをまたいで持ち越される。**
シーンは状態をリセットしない。

これにより、場所も人物も変わらず空気だけが変わる区切りを、書き直しなしで挿入できる。
シーンを細かく切るコストがゼロになり、結果としてセーブのずれ被害が小さくなる
（ずれの被害はシーン長に比例するため）。

場面が本当に変わるときは `@hide *` で明示的に消す。

## 命令一覧

### 作品メタ

| 記法 | 用途 |
|---|---|
| `@title <文字列>` | 作品タイトル |
| `@protagonist <表示名>` | 主人公のネームプレート表示名 |

`@title` はタイトル画面に表示される。タイトル画面は「はじめから／つづきから」の入口であり、
同時に音声再生の解禁点でもある（[バックログと音声の設計](decisions/2026-08-07-backlog-and-audio-design.md) 参照）。

### 背景・音

| 記法 | 用途 |
|---|---|
| `@bg <名前> [fade:<ms>]` | 背景切替 |
| `@bgm <名前>` | BGM 開始 |
| `@bgm stop [fade:<ms>]` | BGM 停止 |
| `@se <名前>` | 効果音 |

**現在鳴っているのと同じ名前の `@bgm` は、鳴らし直さない。** 曲頭に戻らず再生が継続する。

BGM はシーンをまたいで持ち越されるため、シーンの先頭に `@bgm` を書き足しても
曲が頭出しされることはない。同じ曲が続く区間では、書き手は `@bgm` の有無を気にしなくてよい。

### 立ち絵

| 記法 | 用途 |
|---|---|
| `@show <キャラ> [表情] [pos:<位置>]` | 表示・表情変更・位置変更 |
| `@hide <キャラ>` | 退場 |
| `@hide *` | 全員退場 |

`@show` の省略した項目は現在値を維持する。

```
@show mika normal pos:center   初出
@show mika smile               表情だけ変更（位置は維持）
@show mika pos:left            位置だけ変更（表情は維持）
```

初出時に省略された項目は既定値を使う（表情 `normal`、位置 `center`）。

### 進行・演出

| 記法 | 用途 |
|---|---|
| `@wait <ms>` | 間 |
| `@speed slow` / `@speed normal` | 文字送り速度 |
| `@flashback on` / `@flashback off` | 回想の画面効果 |

`@speed` と `@flashback` は明示的に戻すまで持続する。シーンもまたいで持続するため、
戻し忘れると作品の最後まで効き続ける。

`@speed` は読者設定の速度に対する**相対倍率**として働く。
読者が「一括表示」を選んでいる場合は `@speed` を完全に無視し、常に一括表示する。

`@wait` はスキップ機能の対象に含める（スキップ時は飛ばす）。

## 運用ルール

### 持ち越される状態はすべてスナップショットに入る

シーン境界で持ち越される状態は、セーブのシーン入口スナップショットに含めなければならない。
現時点の対象は背景・BGM・立ち絵・変数・`@speed`・`@flashback`。

**`@` 命令を追加するときは、それが持ち越す状態を持つかどうかを判断し、
持つならスナップショットの対象に追加すること。**
これを怠ると、その演出だけ復元されないセーブができあがる。

### 命令を追加する条件

台本に実際に出てきたものだけを追加する。
既存エンジンにあるという理由で追加しない。

（`@move` は当初この一覧にあったが、TyranoScript の `chara_move` を無意識になぞったもので、
台本が要求したものではなかったため `@show` に統合して削除した）

## 意図的に実装しないもの

| 機能 | 理由 |
|---|---|
| 話者名の誤字検出 | 登場人物リストが必要になる。最終確認は人間または AI が行う |
| 話者の付け忘れ検出 | 話者なしは仕様上正しい（主人公の発話）ため、警告がノイズになる |
| 登場人物の登録機能 | 上記2つをやらないため不要 |
| 複数行の同時表示（ブロック結合記法） | 台本に一度も出てきていない |
